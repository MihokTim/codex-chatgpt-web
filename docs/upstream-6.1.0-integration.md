# 上流6.1.0の統合

日付：2026-09-25。識別子：`6.1.0-fork.1`。

上流 `293341084ac7a1ddd2de12fede3706023f5b6474`（Release 6.1.0）を、フォーク `a1c16c72c7d700be2bbdf840f5583e1d643a8121`（6.0.0-fork.8）へ統合する。既存の履歴を維持し、上流コミットを親に含むマージで記録する。

## 採用範囲

上流の新しい入力・応答画面、モデル選択、power slider、添付、Billing、非表示ブラウザー、お知らせダイアログ、ログ、ウィンドウ復元、Windows／Linuxインストーラー、ガイド動画、翻訳、文書および版番号の変更を採用した。フォークに存在する同等処理は一つに統合し、上流だけでは代替できない保証を維持する。

| 項目 | 統合後の契約 |
| --- | --- |
| 会話の識別 | 従来の `data-turn-id-container` と新しい `data-turn-key` を実際の文書順に並べる。後者は `timeline-user:<key>` と `timeline-assistant:<key>` の2つの論理IDを予約する。検索用の内側コンテナは数えない。 |
| 送信と応答の帰属 | 送信前のユーザー境界を維持した新しいユーザーだけを受け付ける。過去IDの再生成、別ユーザーの回答、重複・入れ子・矛盾したユーザー要素を採用しない。空の `client-created-root` 除外も維持する。 |
| 本文と完了 | `data-chatgpt-search-unit-key` と `data-content-search-unit-key` の双方を扱う。後者は同じユニットのassistant役割要素を確認する。ユーザー本文を除き、最終回答の後にある完了操作を確認する。 |
| モデル選択 | 上流のsimple／advanced判定を採用し、advancedでは切替要素を要求しない。日本語等の句読点解析、モデル系統、effort、閉じたメニューと安定した入力欄フォーカスの検証を維持する。 |
| power slider | 外側のメニュー項目と内側のpower controlを二重選択しない。明示されたロック・無効属性と不正な選択値を拒否する。省略されたロック属性は有効なpower trackの中だけで受け付ける。 |
| アプリメンション | 新UIで補助リンク属性がない場合を受け付ける。補助リンクがある場合はメンション先との一致を要求し、重複も拒否する。 |
| 添付・送信 | 新旧の添付タイルを扱う。ファイル入力は所有するcomposerのformに限定する。最終分割送信のactionability確認、送信回数・再送制約を維持する。 |
| 非表示ブラウザー | 上流のランチャー側device emulation管理を採用する。worker側の0サイズ補修は初回統合で維持し、既存のターン所有者を変えない。 |
| Limitsと頻度制限 | Billingの新旧画面を採用する。プラン確認の前後は非キャッシュで照合し、通常のアカウント確認キャッシュ、共有cooldown、Retry-After、429分類は保持する。 |
| 長い推論・圧縮 | Stop表示中の応答DOM猶予更新を採用する。明示的な呼び出し期限、圧縮フェーズ固定、進行証跡、未送信部分だけの復旧を保持する。 |

お知らせの自動終了は、Automaticモードの専用お知らせ領域に限定する。上限・認証・一般の設定ダイアログを一律に閉じる処理ではない。
