# 応答中のブラウザー観測の復旧

送信受理後に DOM の読み取りが止まり、同じページへの再接続でも表示領域の確認がタイムアウトする障害を観測しました。HTTP heartbeat は継続しており、モデル容量不足やモデル選択エラーとは区別します。観測不能のため、その時点の renderer が停止した内部原因や実際の viewport サイズは断定できません。

復旧経路では、再接続の前だけでなく、接続と所有ページの取得が完了した後にも、そのページの表示領域を launcher に再設定させます。最初の再接続の viewport 確認に失敗した場合も、残りの再接続回数を使います。失敗した接続を閉じてから次の接続を開き、同じ所有ページへの接続を最大2回に制限します。

これは同じページの読み取りを復旧する処理です。ChatGPT への再送、ページ再読み込み、新しい会話の生成は行いません。中止・所有者不一致・異種のエラーは再接続の対象にしません。復旧できなければ `chatgpt_browser_viewport_unavailable` と元の例外を保持して終了します。

テストは最初の viewport 失敗からの回復、接続解放順序、残り回数の制限、中止・所有者不一致を確認します。持続的に停止した Chromium renderer や ChatGPT サービス内部の障害を必ず回復できることまでは保証しません。
